# Shop Management System (ShopMS)

A robust, multi-branch, local-first billing and retail management platform designed for scalability and high availability.

### Core Goals
- **Local-First Operations**: Independent branch functionality with local Postgres/Express API.
- **Unified Sync Hub**: Centralized data aggregation for multi-branch reporting.
- **Remote Visibility**: Secure access to branch analytics via Web and Mobile clients.
- **Enterprise-Ready**: Support for hundreds of branches with secure, phased growth.
